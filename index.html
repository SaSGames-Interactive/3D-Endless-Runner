What’s in the game

The current test build includes:

  • Bouncing arcade gameplay

    Guide a square through a 3D world and keep it going as long as you can.

  • High scores

    Your best runs are saved, so every attempt is a chance to beat them.

  • In-game shop

    Browse the shop and spend what you collect.

  • Options

    Change the game’s settings to fit how you like to play.

This is an early version. Features, balance and the game’s name can still change, and tester feedback decides what gets fixed first.

Help test the game

Google requires a group of testers to try the game before it can be released on Google Play. Joining takes about two minutes.
